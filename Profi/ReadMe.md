# "Generation Python": A Course for Professionals

![](Data/logo.png)

https://stepik.org/course/82541/syllabus

This course from Stepik introduces additional Python features, dates and time, advanced collections, iterators, generators, decorators, recursion, exceptions, and regular expressions.
The course consists of 12 modules with theoretical materials, practical exercises, and assignments.
Course Modules:
* Introduction
* Python Basics Review 🐍
* Working with Dates and Time
* File Handling
* Memory Management and Data Types
* Advanced Collections
* Exception Handling
* Recursion
* Functions
* Iterators and Generators
* Regular Expressions
